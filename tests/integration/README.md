# 真实引擎回归 / Real-engine regressions

此目录使用真正的 WB、qPCR、pathology 代码和 Chromium，未替换分析函数。运行前必须具备 `engines.lock.json` 指定的干净引擎修订、各仓库的锁定依赖，以及 pathology 的 Playwright Chromium。缺少依赖或版本不符会失败，不会静默跳过。

These tests execute the real WB, qPCR and pathology engines, including Chromium. They require clean revisions matching `engines.lock.json`, each engine's locked dependencies and the matching Playwright Chromium. Missing dependencies or mismatched revisions fail explicitly instead of silently skipping.

```sh
# 已有引擎并正确配置 / Existing configured engines
WISPLAB_CONFIG=/absolute/path/to/wisplab.config.json npm run test:integration

# 四个仓库的 CI 布局 / CI layout with engines in .engines/wb, .engines/pcr, .engines/ihc
node scripts/configure-integration.mjs
WISPLAB_CONFIG=.integration/config.json npm run test:integration
```

测试自动创建临时数据与配置、选取临时端口并清理文件；不覆盖用户配置或实验数据。CI 的 `Pinned real engines` job 在 Ubuntu / Node.js 24 上安装并执行整个流程。快速测试仍由 `npm test` 独立执行。

Tests create and clean temporary data/configuration, select a temporary port, and do not overwrite user configuration or experimental data. CI's `Pinned real engines` job installs and runs the entire workflow on Ubuntu / Node.js 24. Fast tests remain available separately through `npm test`.

## 数据与期望值 / Fixtures and expectations

`fixtures.mjs` 完全程序化生成输入，无真实实验或厂商数据，按仓库 MIT 许可提供。

All inputs are generated by `fixtures.mjs`, contain no biological/vendor data, and are distributed under the repository's MIT license.

| Fixture | Expected result / 期望依据 |
| --- | --- |
| 8/16-bit WB PNG | Two 30×10 rectangles on a constant background. Contrast 80/40 gives exact local net signals 24000/12000, multiplied by 257 for 16-bit; ratios 1/0.5. |
| qPCR CSV/XLSX | C target Cq=24, reference=20; S target=22,22,40, reference=20. Default ΔΔCt=4 → FC=0.0625. Explicit maxCq=35 exclusion leaves ΔΔCt=−2 → FC=4. |
| Zipped RDML | Same synthetic rows, target efficiency=93%; explicit 92% wins. Pfaffl mean checked against `(2×1.92² + 1.92⁻¹⁶)/3`. |
| IHC RGB PNG | Eight drawn color disks. Fixed-engine regression detects 4 nuclei, threshold 16, background 2, H-score 100; these are regression baselines, **not** proof of segmentation accuracy against 8 drawn disks. |
| IF RGB PNG | Identical R/G channels with a known intensity sequence: Pearson=1; Manders independently summed above the fixed threshold 88. |

`expected.json` stores rolling-ball and control-threshold baselines recorded with pinned engines. IHC counts, thresholds and H-score are implementation regression expectations. They are not an independent scientific calibration or clinical validation. Updating engine revisions requires reviewing changed numerical outputs and intentionally updating documented baselines, never automatically accepting them.

测试同时检查 QC 报告/显式排除、NTC 保留、输入追溯、真实 CLI/MCP 路由和关闭 stdin 后异步结果完整返回。不包含完整 M1/M3/M4 历史基准、全部仪器格式、所有操作系统或生物学分组统计。

Coverage includes QC reporting/exclusion, preserved NTC findings, provenance, actual CLI/MCP dispatch and asynchronous completion after stdin closes. It does not cover the full historical M1/M3/M4 suite, every instrument format/OS or biological-group inference.
